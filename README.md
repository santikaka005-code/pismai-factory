# ระบบชั่งน้ำหนักผลผลิตอัตโนมัติสำหรับโรงงานแปรรูปผลไม้

Automatic Production Weighing System for Fruit Processing Factories (APWS)

เว็บประกอบโครงงาน ใช้รับข้อมูลน้ำหนักจากสถานีชั่ง สรุปผลผลิตรายพนักงาน และคำนวณค่าแรง
สำเนานี้แยกจากระบบใช้งานจริง ดูบัญชีและปลายทางที่ยืนยันแล้วใน `contest-environment.json`
เซิร์ฟเวอร์จะปฏิเสธการเชื่อมต่อหาก SUPABASE_URL ไม่ตรงกับโปรเจคประกวดที่กำหนด

## ฐานข้อมูล

อัปเดตส่วนที่ขาดด้วย `apws-contest-schema-update.sql` เมื่อ 3 พฤศจิกายน 2026
ครอบคลุมสต็อก เบิกผลไม้ ห้องเย็น จองขาย RPC บัญชี เกรดทุเรียน และกลุ่มพนักงาน
ไม่มีคำสั่งล้างข้อมูลธุรกิจ และไม่ย้ายข้อมูลจากระบบจริง

## เริ่มเว็บ

ติดตั้ง `requirements.txt` กำหนด SUPABASE_URL และ SUPABASE_SERVICE_ROLE_KEY ของโปรเจคประกวด
แล้วรัน `python report_server.py` ห้ามใส่ service-role key ในโค้ดหรือ frontend

## สถานะ Desktop

งาน DesktopApp และ Setup พักไว้ตามคำสั่งผู้ใช้วันที่ 3 พฤศจิกายน 2026
ส่วนค้นหาเครื่องของชุดประกวดเตรียมใช้ bridge 127.0.0.1:19766 และรหัส APWS1 เพื่อแยกจาก PWS เดิม
ยังไม่ยืนยันการใช้งานข้ามเครื่องจนกว่าจะทำและทดสอบ Desktop รุ่นประกวด
