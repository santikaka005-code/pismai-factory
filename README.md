# ระบบชั่งน้ำหนักผลผลิตอัตโนมัติสำหรับโรงงานแปรรูปผลไม้

Automatic Production Weighing System for Fruit Processing Factories (APWS)

เว็บประกอบโครงงาน ใช้รับข้อมูลน้ำหนักจากสถานีชั่ง สรุปผลผลิตรายพนักงาน และคำนวณค่าแรง
สำเนานี้แยกจากระบบใช้งานจริง ดูบัญชีและปลายทางที่ยืนยันแล้วใน `contest-environment.json`
เซิร์ฟเวอร์จะปฏิเสธการเชื่อมต่อหาก SUPABASE_URL ไม่ตรงกับโปรเจคประกวดที่กำหนด

## ฐานข้อมูล

อัปเดตส่วนที่ขาดด้วย `apws-contest-schema-update.sql` เมื่อ 3 พฤศจิกายน 2026
ครอบคลุมสต็อก เบิกผลไม้ ห้องเย็น จองขาย RPC บัญชี เกรดทุเรียน และกลุ่มพนักงาน
ไม่มีคำสั่งล้างข้อมูลธุรกิจ และไม่ย้ายข้อมูลจากระบบจริง

## เริ่มเว็บ

ติดตั้ง `requirements.txt` กำหนด SUPABASE_URL และ SUPABASE_SERVICE_ROLE_KEY ของโปรเจคประกวด
แล้วรัน `python report_server.py` ห้ามใส่ service-role key ในโค้ดหรือ frontend

## สถานะ Desktop

APWS Desktop 1.0.0 และ Setup รุ่นประกวดสร้างและทดสอบแล้วเมื่อ 3 พฤศจิกายน 2026
ส่งมอบ Setup แยกให้ผู้พัฒนา ไม่ได้แนบฐานข้อมูลหรือข้อมูลจริงไว้ในตัวติดตั้ง
ใช้ bridge 127.0.0.1:19766 และรหัส APWS1 แยกจาก PWS เดิม เปิดตัวเชื่อมอัตโนมัติ
เว็บค้นหาเครื่อง ส่งรายชื่อ/ผลไม้ และตรวจตัวอย่างข้อมูลชั่งกลับได้แล้ว
เครื่องเดียวกันเชื่อมตัวเองได้ทันที ต่างเครื่องอนุญาตครั้งแรกที่ต้นทางแล้วจำไว้
ทดสอบ EXE/ติดตั้ง/ถอนติดตั้งและการเชื่อมภายในเครื่องแล้ว การใช้งานข้ามคอม/เราเตอร์และเครื่องชั่งจริงยังต้องทดสอบกับอุปกรณ์ปลายทาง

APWS 1.0.1 เพิ่มการเชื่อมผ่าน HTTPS relay: เปิด APWS เฉพาะเครื่องชั่ง กดเชื่อมแล้วนำรหัส 10 หลักไปกรอกในหน้าเว็บดึงข้อมูล ผู้รับต้อง C6+ และใช้บัญชีที่จับคู่ เครื่องเปิดเว็บไม่ต้องเปิด APWS หากแอปหรือเซิร์ฟเวอร์เริ่มใหม่ต้องเชื่อมรหัสใหม่ ส่งน้ำหนักเฉพาะเมื่อกดดึง และต้องตรวจตาราง/ยืนยันเข้าคิวก่อนบันทึกจริง Relay ไม่เก็บประวัติชั่งถาวร
